# 🔐 Tradutor de Cifra de César

Projeto simples desenvolvido com HTML, CSS e JavaScript que realiza a criptografia de textos usando a Cifra de César.

## 🚀 Funcionalidades
- Inserir texto para tradução
- Definir deslocamento (1 a 25)
- Tradução automática em tempo real
- Interface responsiva
- Acessibilidade básica implementada

## 🛠️ Tecnologias
- HTML5
- CSS3
- JavaScript

## 📚 Aprendizados
- Manipulação do DOM
- Eventos em JavaScript
- Lógica de algoritmos
- Responsividade e acessibilidade
